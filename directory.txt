==============================================
KEY ARCHITECTURAL NOTES
==============================================

SESSION FLOW
  Upload → session_id (UUID) created → all subsequent API calls use session_id as path param
  All files keyed by session_id. Session state lives in React SessionContext on the frontend.

FILE SAFETY
  uploads/original/{session_id}.csv  — written once on upload, NEVER modified
  uploads/working/{session_id}.csv   — all clean/transform operations work on this
  uploads/snapshots/{session_id}_snap.csv — overwritten before every apply (enables undo)
  uploads/history/{session_id}.json  — append-only operation log

CACHING STRATEGY
  Profile results cached in backend memory (_profile_cache) — invalidated on any clean/transform apply
  Frontend stores profile result in SessionContext — re-visit does not re-trigger API call
  NLP embeddings: sampled to 2000 rows for datasets > 10,000 rows

API CONVENTIONS
  All endpoints prefixed /api/
  Errors always return: { "error": "...", "detail": "...", "code": 4xx|5xx }
  Never expose Python tracebacks or filesystem paths in responses
  session_id validated as UUID format on every request

DEPLOYMENT TARGETS
  Local Dev   : docker-compose.yml — backend :8000, frontend :5173 (Vite dev server)
  Production  : docker-compose.prod.yml — Nginx on :80/:443, reverse proxies /api → backend container
  CI/CD       : GitHub Actions — test on push, deploy on release tag

GEMINI AI INTEGRATION
  Model             : Gemini 2.0 Flash (free tier)
  Used for          : Profiling insights · EDA natural language questions · Stats plain English explanations
                      Cleaning/Transform recommendation reasoning · ML strategy narrative · Report Executive Summary
                      Persistent AI chat interface (AIChat page)
  Data policy       : Raw user data NEVER sent to Gemini — only computed summaries, stats, and column names
  Prompt location   : backend/prompts/*.txt — version-controlled, editable without code changes
  Fallback          : If Gemini API fails or rate-limits → rule-based response returned automatically
  Response format   : Gemini always prompted to return JSON — parsed and validated before returning to frontend
  Auth              : GEMINI_API_KEY in .env — never committed, never exposed in API responses

ENVIRONMENT VARIABLES (see .env.example)
  BACKEND_PORT         — default 8000
  MAX_UPLOAD_MB        — default 50
  CORS_ORIGIN          — default http://localhost:5173
  UPLOAD_DIR           — path to uploads/ folder
  LOG_LEVEL            — INFO / DEBUG / WARNING
  GEMINI_API_KEY       — Google AI Studio API key (free tier)
  GEMINI_MODEL         — default gemini-2.0-flash
  GEMINI_MAX_RETRIES   — default 3 (retries on rate limit before fallback)
